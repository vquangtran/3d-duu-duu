Quản trị chợ DuuDuu

Thêm mẫu mới, sửa giá, size và ảnh cho chợ.

Máy sẽ nhớ mã này, lần sau mở trang là vào thẳng. Chỉ dán mã trên máy của mình.

Cách lấy mã truy cập (làm một lần)
  1. Đăng nhập GitHub, mở trang tạo mã mới.
  2. Token name: ghi Quản trị chợ. Expiration: chọn thời hạn dài, ví dụ 1 năm.
  3. Repository access: chọn Only select repositories, rồi chọn kho 3d-duu-duu.
  4. Permissions → Repository permissions → Contents: chọn Read and write.
  5. Bấm Generate token, chép mã bắt đầu bằng github_pat_ rồi dán vào ô trên.
